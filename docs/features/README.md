# Feature Ledgers

Feature ledgers track product capability history across iterations. They are project artifacts, not runtime method source.

Use a ledger when a request changes an existing DevFlow-Core product capability. Read the ledger before planning, then update it after the change if the capability version, scope, decision, or constraint changes.
