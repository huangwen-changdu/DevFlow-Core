# 失败卡: 新增函数但套件不覆盖它，全绿是空验证

> 摘要: 用途=防止「加了新函数但既有套件没有对应断言」时把空全绿当达成 | 做了什么=记录触发/根因/修复/防复发，首次写卡 | 复用入口=循环目标要求「新增函数 + 测试全绿」、而既有测试文件未覆盖该函数时 | 更新时间=2026-08-23

- 触发: 需求「在 calc.js 新增 divide2 并让 test.js 全绿」；基线 `node demo/test.js` 本就 exit 0——因为 test.js 只覆盖 subtract/multiply/divide。若只加函数不改测试，停止条件「exit 0」会立即通过，但 divide2 行为（含除零抛错）完全没被验证。
- 根因: 停止条件只盯退出码，不检查「新功能是否真的被测到」；把「套件绿」误当作「新代码验证过」。
- 修复: R1 基线阶段先查既有断言覆盖面（grep 新函数名是否出现在测试文件）；未覆盖则补最小断言集（与 divide 两态对齐：正常除 + 除零抛错），不改既有断言语义；决策理由写入状态文件 R1。
- 防复发: 任何「新增函数 + 全绿」型目标，先确认测试文件引用并断言新函数；「全绿」必须包含新函数本身的验证才有意义。
