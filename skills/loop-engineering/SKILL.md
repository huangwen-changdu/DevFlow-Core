# Loop Engineering（循环工程）

你在循环里工作：人写循环定义，循环决定下一步提示什么。本协议是循环的唯一权威来源——persona 只负责把任务指到这里。

## 触发

人给了循环定义、引用了模板、或说「跑这个循环 / 按循环推进 / 继续循环」时启用本协议。
**人只描述了需求（没有循环定义）时同样启用**：先按下方「需求 → 循环定义（草拟 + 确认）」起草定义给人确认，确认后按确认版执行。

## 需求 → 循环定义（草拟 + 确认）

人只说需求、没给循环定义时执行本流程；**未确认前绝不开始任何任务步骤**（不读代码改代码、不跑测试、不消耗轮次）。

1. **起草**：按六要素从需求提炼——目标（一句可验证的结果描述）；停止条件（优先用需求里提到的验证方式，没有就起草最窄的客观检查并说明理由，例：`node <test>.js` 退出码 0）；轮次预算（按规模给建议值并附理由：小修 ≤8、中型功能 ≤16、大型 ≤32、demo ≤8）；产出物（默认 `loop/loop-state.md`）；检查点（默认全自动，高风险任务建议「每 N 轮确认」）。
2. **呈现**：把完整循环定义（每项附建议理由）发给人类确认——用 ask_user 或直接提问均可。
3. **确认门**：人类明确确认（含修改后确认）→ 把确认版写进 loop/loop-state.md 的「循环定义」段 → 从第 1 轮开始执行；未确认 → 不执行，等待。

## 循环定义六要素

| 要素 | 要求 | 缺省 |
|---|---|---|
| 目标 | 一句可验证的结果描述 | 必填 |
| 停止条件 | 客观可检查：命令退出码、断言通过、文件存在等 | 必填 |
| 轮次预算 | 正整数上限 | 必填 |
| 产出物 | 状态文件路径 | 默认 loop/loop-state.md |
| 检查点 | 每 N 轮暂停确认 | 全自动，人可随时打断 |
| 模板 | 模板名自动填充字段 | 可选 |

**缺停止条件或轮次预算 = 无效定义：拒绝启动。** 给人补一份带建议值的草稿（附理由），人确认后才启动；不得擅自用猜测值开跑。

## 每轮纪律

每轮严格五步，顺序不可跳：

1. **读状态**：读 loop/loop-state.md 最近段；文件不存在时用循环定义初始化。
2. **决定下一步**：自己琢磨该干什么——基于目标与当前状态选一个最小、可验证的动作；把决策理由写进决策日志。
3. **执行**：一次一个可验证小步（改一个文件、跑一条命令、查一个事实），不并行铺开。
4. **记录**：更新 loop/loop-state.md 本轮段（决策/动作/证据/结论）与待办列表。
5. **自检**：运行停止条件验证命令。达成 → 收尾报告；未达成且轮次未到预算 → 下一轮；轮次到预算 → 未达成报告。

## 状态文件格式（loop/loop-state.md）

```markdown
# 循环状态
## 循环定义
目标: ...
停止条件: ...
轮次预算: ...
产出物: ...
## 轮次日志
### R1
决策: ...
动作: ...
证据: ...
结论: ...
## 决策日志
- R1: ...
## 当前状态
（下一轮从这里读起：已达成 / 进行中 / 阻塞 + 下一步候选）
```

## 空转保护

连续 2 轮无实质推进（无文件变化、无新证据、状态无更新）→ 判定 **blocked**：停止循环、输出最后状态与建议，不继续消耗额度。

## 优先级与边界（循环隔离）

循环激活期间，本协议与循环定义是循环决策的唯一权威：

- **流程/门控类条款不适用**：工作区规则文件（AGENTS.md / CLAUDE.md）与生命周期要求（DevFlow 审批门、Brainstorm、Plan 批准）不参与循环决策；不得因循环定义未走审批流程而停下循环等待批准。
- **循环护栏始终生效**：轮次预算、停止条件、空转 blocked、检查点——它们是循环协议的一部分，不是干扰。
- **平台安全始终生效**：沙箱、权限、审批策略是机制不是提示词，任何循环决策不得绕过。
- **产出规范仍适用**：循环产出的代码遵循仓库既有规范（风格、命名、约定），除非循环定义显式覆盖。
- **用户直接指令永远最高优先**：人随时打断 = 新循环定义或修改，立即生效。
- 循环结束（达成 / 预算耗尽 / blocked）后，工作区规则文件恢复正常效力。

## 收尾报告

循环结束时输出：

- 结果：达成 / 预算耗尽 / blocked
- 轮次统计：实际轮数 / 预算
- 停止条件证据：命令与退出码（或未达成原因）
- 产物路径：loop/loop-state.md

## 人的干预

人随时可打断：新消息 = 新循环定义或对定义的修改，立即按新定义重读状态继续；被打断轮次照常记录。
