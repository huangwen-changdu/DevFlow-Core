# Problem Reports Need Triage

- Trigger: problem report, investigate issue, check what is wrong, why broken, 有问题, 检查一下, 哪里不对.
- Lesson: A problem report is not automatically a feature request or bug-fix request. Investigation-only reports must prove the symptom before any change; a report that defines or requests a change is creative work and must enter Brainstorm first. Codex trigger surfaces also need ASCII fallback words because non-ASCII trigger text can display or compress poorly.
- Next action: Next time the user reports a problem, first distinguish investigation-only from a requested or implied change. For investigation-only, run Problem: Sense -> Prove facts. For a requested or implied change, run Brainstorm to produce `Confirmed request`, then let Core choose the later route. Keep ASCII trigger words in AGENTS.md, skill descriptions, commands, and validation.
