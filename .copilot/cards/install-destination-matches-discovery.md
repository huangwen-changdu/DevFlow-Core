# Install Destination Must Match Host Discovery

- Trigger: install destination, install:target 落位, skills 复制到项目, 同步到其他项目, skill 发现不了, 技能扫描不到, .agents/skills, host skill root, skills/ 旧布局, stale skills, 项目级技能目录
- Lesson: 运行时文件的落位和宿主的发现约定是同一个契约的两端。`install:target` 把 `skills/**` 原样复制到 `<目标>/skills/**` 时，读共享技能根的宿主永远扫不到；只改复制目标而不改入口文本，目标又会拿到指向不存在目录的 `AGENTS.md`、adapter 和命令。已证实的最小闭环：项目级技能落 `.agents/skills/`，源仓库保留 `skills/`（插件元数据、DSH 资产、校验器都读它），`AGENTS.md` 声明 skill root 并把 `skills/...` 解析到该根，manifest 记安装路径。迁移判据要同时认"与安装包字节一致"和"与旧 manifest 哈希一致"，且比较前归一化 CRLF——Windows 检出会把旧包副本变成 CRLF，只比新版本字节会把整棵旧树误判成本地改动。
- Rejected: 双写 `skills/` 与 `.agents/skills/`、或建目录 junction —— 被否：两套字节必然漂移，junction 在 Windows + git 下不可移植。只改复制目标而不改 `AGENTS.md`、adapter、命令入口 —— 被否：会留下指向旧目录的断链。迁移只比新版本字节 —— 被否：跨版本升级时旧包副本天然不同，会全部保留（实测 3 个项目各 31 个）。
- Next action: 下次改安装落位或同步路径时，先确认宿主发现约定（项目 `.agents/skills`、用户 `~/.agents/skills`），再把落位映射、入口文本、manifest 键、校验器和迁移路径当成同一个改动提交；迁移用 `doctor:target` 检查、`--migrate` 清理，判据同时认"与安装包字节一致"与"与旧 manifest 哈希一致"，比较前归一化 CRLF，整目录删之前先确认项目自有技能。其他项目侧用随运行时下发的 `scripts/devflow-skills.js` 自查/清理，不要求对方装 DevFlow-Core。
- Scope: project
- Related: `scripts/install-devflow.js`, `scripts/validate-installer.js`, `AGENTS.md`, `docs/platform-setup.md`, `docs/hotfix-log.md`, `.copilot/cards/skill-sync-after-update.md`
- Evidence: 2026-11-18 实测 KocServer 只有 `<project>/skills/`（DevFlow 0.8.1）且无 `.agents/`，hetu 的第三方技能放在 `.agents/skills/`；改写后 `npm run install:verify` 断言新目标只生成 `.agents/skills/`、不生成 `skills/`、旧 `skills/devflow-core/SKILL.md` 被 `--check` 报 `stale:` 且 exit 1；`AGENTS.md` 8180/8192 字节 PASS。2026-11-18 补迁移工具：`--migrate` 隐含 `--write`，只删与安装包字节一致或与旧 manifest 哈希一致的旧文件（1 removed / 1 kept 用例），差异文件保留、空目录清理、项目自有技能不动；`npm run doctor:target -- <project>` 复用 `--check`，KocServer pass、KocTask fail 并打印 migrate 命令；doctor self-test 覆盖 clean → legacy fail → migrate pass。同日对 4 个真实项目落地：KocTask / CdFinanceWebApi / KocWebApi / MoboTreeServer（未安装）。跨版本旧包副本与新版本天然不同，首轮 31×3 全部被 kept；改为认旧 manifest 哈希 + CRLF 归一化后，31/31、29/31、16/18 命中删除；剩余 4 个经比对是 pre-baseline 的 DevFlow 旧版（git 跟踪且干净）后删除。KocTask 的 AOCI 章节 6,757 字符原样回填；KocWebApi `.claude/settings.json` 的 3 条 permissions 合并保留；KocTask `skills/hangfire-task-template` 未动。最终 3 个项目 `--check` pass，KocTask 仅 `changed: AGENTS.md`（本地 AOCI 扩展）。2026-11-20 补项目内工具：`scripts/devflow-skills.js` 随项目运行时下发（不依赖 DevFlow-Core），默认查 `.agents/skills`/AGENTS root/旧 `skills/`，`--migrate` 只删已验证副本、`--migrate --force` 显式全删、`--json`、self-test；6 个真实项目同步后脚本 `ok:true`，5 个 `--check` pass、KocTask 仅本地 AGENTS。
- Evidence Level: L1
- Invalidation: 宿主发现约定或项目级安装落位再次变化（例如 `.agents/skills` 被弃用）时修订。
