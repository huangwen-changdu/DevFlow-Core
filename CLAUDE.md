# DevFlow Core v2

Follow the shared rules in [AGENTS.md](AGENTS.md). User instructions override framework defaults.

Use `devflow-core` for normal development work when skills are available. Use `devflow-brainstorm` for requirements and design, `devflow-cut` for reuse and overengineering checks, `devflow-build` for minimal implementation, `devflow-pua` when the user challenges a wrong or repeated miss, and `devflow-prove` before reporting success.

Required completion proof:

```text
Command:
Result:
Judgment: PASS / FAIL / BLOCKED
```
