# 循环模板：实现功能到测试绿

选中本模板后，把「示例」块整体复制进会话并替换字段。

## 字段

```markdown
# 循环定义
目标: 实现「功能描述」，行为满足「验收点」
停止条件: `node 测试命令` 退出码 0 且覆盖「验收点」的断言全部通过
轮次预算: 8
规模评级: 模型自判（预算为线索；小任务免路线图与子目标链）
产出物: loop/loop-state.md
检查点: 每 2 轮确认一次（可选；删除该行即全自动）
```

## 示例

```markdown
# 循环定义
目标: 在 demo/calc.js 中实现 multiply，乘法的输入输出正确
停止条件: `node demo/test.js` 退出码 0 且 multiply 断言全部通过
轮次预算: 8
产出物: loop/loop-state.md
```

## 规则

- 第一轮先写失败断言（证明功能还不存在），把失败证据写进状态文件，再实现到绿。
- 停止条件命令每轮必跑，退出码写进状态文件。
- 实现按最小切片推进：先让一个断言绿，再下一个，不一次铺开。

## 中大任务区块（可选，模型自判启用）

```markdown
子目标链:
- 子目标1: 失败断言先行（停止条件: 断言覆盖验收点且运行失败）
- 子目标2: 实现到绿（停止条件: `node 测试命令` 退出码 0）
路线图:
- 步骤1: 写失败断言 → 验证点: 断言失败入状态文件
- 步骤2: 最小实现 → 验证点: 测试退出码 0
- 步骤3: 收尾对抗轮 → 验证点: 对抗结论入状态文件
```
