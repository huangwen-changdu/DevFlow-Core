# 循环模板：通用任务

不限定编码领域；任何可分解、可验证的目标都可以跑。选中本模板后替换字段。

## 字段

```markdown
# 循环定义
目标: 「一句可验证的结果描述」
停止条件: 「客观可检查判据：命令退出码 / 断言通过 / 文件内容 / 事实核对」
轮次预算: 8
规模评级: 模型自判（预算为线索；小任务免路线图与子目标链）
产出物: loop/loop-state.md
检查点: 无（可随时打断）
```

## 示例

```markdown
# 循环定义
目标: 汇总 docs/ 下所有 spec 文件的设计决策到 docs/SUMMARY.md
停止条件: `node scripts/check-summary.js` 退出码 0 且 docs/SUMMARY.md 含全部 spec 标题
轮次预算: 8
产出物: loop/loop-state.md
```

## 规则

- 停止条件必须能被命令或文件客观验证；无法客观验证的目标，先把它改写成可验证形式再启动循环。
- 每轮必须产生可验证推进（新文件、新内容、新证据）；连续两轮无推进即 blocked 上报。
- 研究/调查类任务把证据链写进状态文件的「证据」字段，收尾报告给出结论与依据。

## 中大任务区块（可选，模型自判启用）

```markdown
子目标链:
- 子目标1: 「第一段可独立验证的小目标」（停止条件: 「该段判据」）
- 子目标2: 「第二段小目标」（停止条件: 「该段判据」）
路线图:
- 步骤1: 「第一步」 → 验证点: 「怎么证明完成」
- 步骤2: 「第二步」 → 验证点: 「怎么证明完成」
- 收尾对抗轮 → 验证点: 对抗结论入状态文件
```
